# Bhavya Bansal

Personal site for research, projects, writing, and the rest of the picture that a resume cannot hold. Built with [Astro](https://astro.build) and published on GitHub Pages.

**Fill in real content:** see [CONTENT.md](CONTENT.md).

## Local

Node 22 or newer.

```sh
npm install
npm run dev
```

The site is served at `http://localhost:4321/Portfolio/` (project-page base path).

```sh
npm run build
npm run preview
```

## Deploy

Push to `main`. GitHub Actions builds the static site and deploys it to GitHub Pages. Enable Pages in the repository settings with **Source: GitHub Actions**.
