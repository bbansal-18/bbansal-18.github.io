I'm Bhavya, a CS major at Carnegie Mellon with a minor in Machine Learning and Computational Finance, and I've spent most of my time outside class actually building systems end to end: from mobile apps to live platforms.

In summer 2026, I interned at MasterTrust, where I built a live execution system that handled real-time price monitoring and order routing across multiple accounts, plus a backtesting engine to validate strategies before anything went live, which was a high-level practice in building software that has to be both fast and correct at the same time. Before that, at HNI Investor, I built a real-time dashboard that pulled data through a VBA-driven Excel pipeline, streamed it over WebSockets, and rendered it in React, thereby stitching three very different pieces of tech into something that actually worked reliably.

Outside of internships, I enjoy building full products on my own. My Med Tracker is a React Native app for managing medication schedules and reminders, secured with RSA-encryptions, and it grew to more than 1,500 patients and ten-plus doctors before I eventually moved on. More recently, I built a full-stack app pairing a Monaco-based code editor to solve interesting DSA problems with an LLM tutor called AI Study Buddy, where I had to get pretty disciplined about parsing model output reliably and keeping the whole loop fast.

I've also worked in a less code-heavy, more structured environment at CMU's Data Governance Office, helping write and clean up the definitions the university uses to trust its own data, which taught me a lot about working with non-engineers.

Across all of it, I've kept a 4.0 while carrying two technical minors alongside core CS. What I like most is building the parts underneath, the pipeline, the sync, the real-time layer, the stuff that has to work efficiently. I wish to continue working on such projects, but on a larger scale with possibilities for a greater impact.
